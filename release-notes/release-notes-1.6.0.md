## Drxwnify — теперь отдельное приложение

- **Как перейти:** в старом Drxwnify нажми «Обновить» — данные сохранятся в `Download/Drxwnify`, установится новое приложение. Открой его и выбери этот файл. Старое потом удали.
- **Ничего не теряется** — аккаунты, лайки, плейлисты, настройки, друзья
- **Скачанная музыка** играет прямо из папки, без повторной загрузки

## Исправлено

- Треки снова находятся после перезапуска
- Приложение никогда не удаляет файлы из папки с музыкой само
