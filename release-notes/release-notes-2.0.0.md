## Drxwnify 2.0.0 — отдельное приложение

Из-за возможных юридических проблем Drxwnify переехал на собственный системный идентификатор, поэтому ставится как новое приложение.

**Как перейти**
1. В старом Drxwnify: Настройки → Резервное копирование → «Создать резервную копию»
2. Установи 2.0.0 → Настройки → Резервное копирование → «Восстановить из резервной копии»
3. Удали старое приложение — оно больше не обновляется

Вернутся аккаунты, лайки, плейлисты с обложками, настройки и друзья. Скачанная музыка играет прямо из папки.
