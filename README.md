## Что это

**Drxwnify** — музыкальный плеер для Android, в котором всё берётся из твоего аккаунта: медиатека, плейлисты, «Любимые треки», альбомы, исполнители и поиск. Звук для каждого трека приложение находит само в нескольких источниках одновременно. Premium и подписки не нужны.

<table>
<tr>
<td width="50%" valign="top">

### 📚 Твоя медиатека
- Вход в **Spotify** или **Яндекс Музыку** прямо в приложении
- Плейлисты, альбомы, исполнители и «Любимые треки» как в оригинале
- Лайки, сохранённые альбомы и подписки синхронизируются в обе стороны
- Поиск ставит точные совпадения первыми

- Строгая проверка по названию, исполнителю и длительности
- Не та запись — выбери нужную вручную в меню трека
- Если источник не отвечает, играет следующий

## 🔊 Источники звука

| Источник | Что даёт | Нужен вход |
|:--|:--|:--:|
| **YouTube** | Самый большой каталог | — |
| **SoundCloud** | Независимые артисты, ремиксы | — |
| **VK Музыка** | Много русскоязычной музыки | ✔ |
| **Bandcamp** | Независимые лейблы и релизы | — |
| **Audius** | Открытая музыкальная платформа | — |
| **Soulseek** | Редкие релизы и lossless, крайний вариант | ✔ |

Порядок и включение источников настраиваются в **Настройки → Интеграции → Источники музыки**.

## 🔒 Приватность

- **Нет своего сервера, рекламы и аналитики.** Приложение ничего о тебе не собирает.
- **Всё хранится на телефоне:** аккаунты, лайки, настройки и загрузки.
- **Запросы идут напрямую** в Spotify, Яндекс Музыку, YouTube и другие источники, как из браузера.
- **Совместное прослушивание, Discord и Soulseek** работают, только если ты сам их включишь.
- **Код открыт:** можно проверить и собрать приложение самому.

## 📥 Установка

1. Скачай `Drxwnify.apk` со страницы [**Releases**](https://github.com/DrxwnSlvt/Drxwnify/releases/latest).
2. Открой файл и разреши установку из этого источника.
3. При первом запуске подключи Spotify или Яндекс Музыку.

Обновления: **Настройки → Проверить обновления**. Новая версия скачивается и ставится поверх старой, данные сохраняются.

> Требуется Android 8.0 или новее.

## 🛠 Сборка из исходников

Нужны JDK 21 и Android SDK.

```bash
git clone https://github.com/DrxwnSlvt/Drxwnify.git
cd Drxwnify
./gradlew :app:assembleFossRelease
```

Готовый APK: `app/build/outputs/apk/foss/release/`.

## ❓ Вопросы

<details>
<summary><b>Нужен ли Spotify Premium или подписка Яндекс Плюс?</b></summary>
<br/>
Нет. Из аккаунта берутся только медиатека и информация о треках, а звук приложение находит в других источниках.
</details>

<details>
<summary><b>Играет не та версия трека. Что делать?</b></summary>
<br/>
Открой меню трека (⋯) → «Выбрать источник звука» и выбери нужную запись. Выбор запоминается.
</details>

<details>
<summary><b>Куда сохраняются загрузки?</b></summary>
<br/>
По умолчанию в <code>Music</code> на телефоне. Папку можно поменять в настройках хранилища.
</details>

<details>
<summary><b>Можно ли подключить и Spotify, и Яндекс Музыку?</b></summary>
<br/>
Да. Аккаунты не смешиваются: в настройках выбирается, какой из них даёт медиатеку и поиск.
</details>
