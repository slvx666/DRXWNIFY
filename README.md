## ⚡ О проекте Drxwnify

**Drxwnify** — музыкальный плеер для Android, в котором всё берётся из твоего стримингового аккаунта: медиатека, плейлисты, «Любимые треки», альбомы, исполнители и поиск. Звук для каждого трека приложение находит автоматически в нескольких независимых источниках одновременно. Premium-подписка не требуется.

## 🔒 Приватность и Безопасность

- **Нет сторонних серверов, рекламы и телеметрии.** Приложение ничего не собирает.
- **Всё хранится локально на устройстве:** токены, кеш, настройки и скачанная музыка.
- **Прямые запросы** в Spotify, Яндекс Музыку, YouTube и другие сервисы без посредников.
- **Код полностью открыт:** вы можете собрать приложение самостоятельно.

## 📥 Установка

1. Скачайте актуальный `Drxwnify.apk` со страницы [**Релизов**](https://github.com/slvx666/DRXWNIFY/releases/latest).
2. Откройте файл и разрешите установку.
3. При первом запуске подключите аккаунт Spotify или Яндекс Музыки.

Обновления проверяются в **Настройки → Проверить обновления**. Обновление ставится поверх, данные сохраняются.

> Требуется Android 8.0 или новее.

## 🛠 Сборка из исходников

Для сборки требуются JDK 21 и Android SDK:

```bash
git clone https://github.com/slvx666/DRXWNIFY.git
cd DRXWNIFY
./gradlew :app:assembleFossRelease
```

Готовый APK появится в: `app/build/outputs/apk/foss/release/`.

## ❓ Часто задаваемые вопросы

<details>
<summary><b>Нужен ли Spotify Premium или подписка Яндекс Плюс?</b></summary>
<br/>
Нет. Каталог используется исключительно для медиатеки и рекомендаций, а аудиопотоки приложение находит в открытых источниках.
</details>

<details>
<summary><b>Как проверить настоящее качество аудио?</b></summary>
<br/>
В меню трека выберите «Спектрограмма трека» — приложение построит точный спектр частот, по которому сразу виден реальный срез частот и качество дорожки.
</details>

<details>
<summary><b>Куда сохраняются скачанные файлы?</b></summary>
<br/>
По умолчанию в папку <code>Music</code> на телефоне. Путь можно изменить в настройках хранилища.
</details>

<details>
<summary><b>Как поделиться целым альбомом или плейлистом?</b></summary>
<br/>
После скачивания альбома или плейлиста кнопка загрузки разделяется на две кнопки: удалить или отправить все файлы разом в любой мессенджер / файлообменник.
</details>
